The Problem We Solve

HR departments struggle to measure employee well-being beyond annual surveys. EmotionAI closes that gap.

😞

The Challenge

Traditional employee well-being tools rely on self-reported surveys that are infrequent, biased, and slow. HR managers have no objective, real-time view of the team's emotional climate — especially during events and stressful periods.

🚀

Our Solution

EmotionAI captures emotional state automatically via a selfie at key moments (company events, logins), classifies it using state-of-the-art AI, and surfaces aggregated analytics to HR — all without manual input from employees.

Core Features

Everything an HR department needs to monitor, understand, and improve psychological climate.

🧠

Facial Emotion Recognition

Deep learning model detects 7 emotions from a single selfie — happy, sad, angry, fearful, disgusted, surprised, neutral — with confidence scores.

🔐

Biometric Face Login

Employees authenticate with their face using FaceNet (InceptionResnetV1 + MTCNN). Three-verdict system: YES, NO, RETRY — secure and frictionless.

📊

HR Analytics Dashboard

Filter emotion feedback by date range, department, event, or emotion type. Visual charts built with Jetpack Compose and MPAndroidChart.

📅

Event-Linked Feedback

HR creates company events and invites employees. Each selfie submission is tied to an event, enabling precise before/during/after emotional comparisons.

💬

Real-Time HR Ticketing

Employees open support requests to HR managers. Messages are delivered instantly via WebSocket — no polling, no delays.

📱

Native Android App

Kotlin app with dual-role navigation (Employee / HR), CameraX for selfie capture, and Jetpack Compose analytics screens — fully offline-capable auth.

How It Works

From selfie to insight in seconds.

1

Employee Takes Selfie

Via the Android app at any active company event or during face login.

2

Backend Receives Photo

Django compresses and forwards the image to the AI microservice over internal Docker network.

3

AI Model Classifies

FastAPI service runs the HuggingFace transformer pipeline and returns emotion label + top-3 probabilities.

4

Feedback Stored

Result is saved in PostgreSQL linked to user, company, department, and event.

5

HR Views Analytics

HR manager filters and explores aggregated emotion data across the organisation.

Two Roles, One Platform

Complete data isolation between organisations; separate navigation flows per role.

👩‍💼

HR Manager

Management Role
  • Create and manage company events with assigned participants
  • View emotion analytics filtered by date, department, or event
  • Browse all employees in the company
  • Receive and respond to employee support tickets
  • Progress ticket status: Open → In Progress → Closed
👨‍💻

Employee

Contributor Role
  • Submit selfie feedback for active events (one per event)
  • Log in with face biometrics for frictionless authentication
  • View personal active events
  • Open support requests to HR managers
  • Exchange real-time messages in ticket chat

AI Models Under the Hood

Two independent AI components — emotion detection and face verification — running in a dedicated FastAPI microservice.

HuggingFace Transformers

Emotion Detection

Model: dima806/facial_emotions_image_detection
Image classification pipeline on CPU. Returns confidence scores for all 7 classes.

Happy Sad Angry Fear Disgust Neutral Surprise
FaceNet / PyTorch

Face Authorization

MTCNN for multi-scale face detection + InceptionResnetV1 (VGGFace2 pretrained) for 512-dim embedding. Cosine similarity with two thresholds:

≥ 0.75 → YES (authenticated)
≥ 0.65 → RETRY (unclear)
< 0.65 → NO (rejected)
